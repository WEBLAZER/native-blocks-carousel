# Any Block Carousel Slider

Transform any WordPress block (Columns, Query Loop/Post Template, Group, Gallery) into a performant, responsive carousel with native CSS scroll-snap. Extremely lightweight JavaScript handles navigation, loop, and autoplay controls.

## 🚀 Try it now (Interactive Demo)

Experience the plugin in seconds with **WordPress Playground**! No installation required:

**[Launch Interactive Demo](https://playground.wordpress.net/?blueprint-url=https://native-blocks-carousel.weblazer.fr/playground/blueprint.json)**

---

## Why Any Block Carousel Slider?

- **Native Scroll & Performance**: GPU-friendly, native CSS scroll-snap layout. No heavy external libraries like Swiper/Slick.
- **WordPress Native**: Works directly on your existing Columns, Query Loop, Group, or Gallery blocks.
- **Lightweight**: No external dependencies. Extremely lightweight script (~40KB raw source, <15KB minified/gzipped) for controls, loop, and autoplay.
- **Performance**: High Lighthouse scores out of the box.

## Installation

1. Download the plugin.
2. Upload it to your WordPress site.
3. Activate it and enjoy!
